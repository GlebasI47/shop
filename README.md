# TechShop — интернет-магазин электроники

Дипломный проект курса Python (Teach Me Skills): веб-приложение интернет-магазина на Django и PostgreSQL.

## Возможности

- Каталог товаров с фотографиями, категориями и ценами.
- Фильтр по категориям и поиск по названию (без учёта регистра); фильтр и поиск работают вместе.
- Страница товара с фото и описанием (для несуществующего товара — ответ 404).
- Регистрация, вход и выход (сессионная аутентификация Django), проверка пароля по каждому полю.
- Корзина: добавить товар, изменить количество кнопками «−» и «+», удалить строку, итоговая сумма. Доступна только вошедшим пользователям.
- Оформление заказа без платёжной системы: строки корзины переносятся в заказ с ценой на момент покупки, корзина очищается (всё внутри транзакции).
- Страница «Мои заказы» с историей покупок.
- Информационные страницы: «Помощь» (частые вопросы), «Доставка и оплата», «Контакты».
- Добавлять, изменять и удалять товары и категории может только администратор (через админку Django).
- Адаптивная вёрстка: сайт удобно открывать и с телефона.

## Стек

- Python 3.14
- Django 6.1
- PostgreSQL 18 (драйвер psycopg 3)
- Pillow (фотографии товаров)
- python-dotenv (настройки из файла `.env`)
- HTML-шаблоны Django + CSS

## Установка и запуск

1. Клонировать репозиторий и перейти в папку проекта:
   ```
   git clone https://github.com/GlebasI47/shop.git
   cd shop
   ```
2. Создать и активировать виртуальное окружение (Windows):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Создать в PostgreSQL базу и пользователя (в psql):
   ```sql
   CREATE USER shop_user WITH PASSWORD 'ваш_пароль' CREATEDB;
   CREATE DATABASE shop_db OWNER shop_user;
   ```
   Право `CREATEDB` нужно, чтобы Django мог создавать временную базу для тестов.
5. Скопировать `.env.example` в `.env` и вписать свои значения (`DB_PASSWORD`, `SECRET_KEY`).
6. Применить миграции и создать администратора:
   ```
   python manage.py migrate
   python manage.py createsuperuser
   ```
7. Запустить сервер:
   ```
   python manage.py runserver
   ```
   - сайт: http://127.0.0.1:8000/
   - админка: http://127.0.0.1:8000/admin/ — здесь добавляются категории и товары с фото.

Загруженные фото товаров хранятся в папке `media/` и в Git не попадают.

## Тесты

```
python manage.py test
```

16 тестов в `store/tests.py`, запускаются на отдельной временной базе:

- **unit-тесты** моделей: `Product.__str__`, `CartItem.total_price`;
- **интеграционные тесты** (запрос → ответ через тестовый клиент Django):
  - доступ и ошибки: каталог (200), несуществующий товар (404), добавление в корзину без входа (редирект на вход), GET на действие корзины (405);
  - корзина и заказ: повторное добавление увеличивает количество, кнопки «+» и «−» (при нуле строка удаляется), удаление чужой строки корзины (404), оформление пустой корзины (400), оформление заказа (заказ создан, цена сохранена, корзина очищена);
  - каталог: фильтр по категории, поиск без учёта регистра, неверный параметр категории не ломает страницу (200);
  - регистрация со слабым паролем (ошибки по полям, пользователь не создан);
  - информационные страницы открываются для гостя (200).

## Структура данных

| Модель | Поля | Назначение |
|---|---|---|
| `Category` | name | категория товара |
| `Product` | category, name, description, price, in_stock, image | товар |
| `CartItem` | user, product, quantity (пара user+product уникальна) | строка корзины |
| `Order` | user, created_at, total | оформленный заказ |
| `OrderItem` | order, product, quantity, price | строка заказа с ценой на момент покупки |

## Адреса

| Адрес | Что делает | Доступ |
|---|---|---|
| `/` | каталог; параметры `?category=<id>` и `?q=<текст>` | все |
| `/product/<id>/` | страница товара | все |
| `/register/` | регистрация | все |
| `/accounts/login/`, `/accounts/logout/` | вход и выход | все |
| `/help/`, `/delivery/`, `/contacts/` | помощь, доставка, контакты | все |
| `/cart/` | корзина | вошедшие |
| `/cart/add/<id>/` | добавить в корзину (POST) | вошедшие |
| `/cart/increase/<id>/`, `/cart/decrease/<id>/` | изменить количество (POST) | вошедшие, только свои строки |
| `/cart/remove/<id>/` | удалить из корзины (POST) | вошедшие, только свои строки |
| `/cart/checkout/` | оформить заказ (POST) | вошедшие |
| `/orders/` | мои заказы | вошедшие |
| `/admin/` | управление товарами и категориями | только администратор |

## HTTP-статусы

- **200** — страница открыта.
- **302** — перенаправление (например, на страницу входа, если пользователь не вошёл).
- **400** — оформление пустой корзины.
- **403** — запрос формы без CSRF-токена.
- **404** — товар или строка корзины не найдены (в том числе чужая строка).
- **405** — действие, меняющее данные, вызвано методом GET вместо POST.
