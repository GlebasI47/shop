# Интернет-магазин

Дипломный проект курса Python (Teach Me Skills): веб-приложение интернет-магазина на Django и PostgreSQL.

## Возможности

- Каталог товаров с категориями и ценами.
- Страница товара с описанием (для несуществующего товара — ответ 404).
- Регистрация, вход и выход (сессионная аутентификация Django).
- Корзина: добавить товар, посмотреть список и итоговую сумму, удалить строку. Доступна только вошедшим пользователям.
- Оформление заказа без платёжной системы: строки корзины переносятся в заказ с ценой на момент покупки, корзина очищается.
- Страница «Мои заказы» с историей покупок.
- Добавлять, изменять и удалять товары и категории может только администратор (через админку Django).

## Стек

- Python 3.14
- Django 6.1
- PostgreSQL 18 (драйвер psycopg 3)
- python-dotenv (настройки из файла `.env`)

## Установка и запуск

1. Клонировать репозиторий и перейти в папку проекта:
   ```
   git clone https://github.com/GlebasI47/shop.git
   cd shop
   ```
2. Создать и активировать виртуальное окружение (Windows):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Создать в PostgreSQL базу и пользователя (в psql):
   ```sql
   CREATE USER shop_user WITH PASSWORD 'ваш_пароль' CREATEDB;
   CREATE DATABASE shop_db OWNER shop_user;
   ```
   Право `CREATEDB` нужно, чтобы Django мог создавать временную базу для тестов.
5. Скопировать `.env.example` в `.env` и вписать свои значения (`DB_PASSWORD`, `SECRET_KEY`).
6. Применить миграции и создать администратора:
   ```
   python manage.py migrate
   python manage.py createsuperuser
   ```
7. Запустить сервер:
   ```
   python manage.py runserver
   ```
   - сайт: http://127.0.0.1:8000/
   - админка: http://127.0.0.1:8000/admin/

## Тесты

```
python manage.py test
```

11 тестов в `store/tests.py`:
- **unit-тесты** моделей: `Product.__str__`, `CartItem.total_price`;
- **интеграционные тесты** (запрос → ответ): каталог (200), несуществующий товар (404), добавление в корзину без входа (редирект на вход), GET на действие корзины (405), повторное добавление увеличивает количество, удаление чужой строки корзины (404), оформление пустой корзины (400), оформление заказа (заказ создан, цена сохранена, корзина очищена), регистрация со слабым паролем (ошибки по полям).

## Структура данных

| Модель | Поля | Назначение |
|---|---|---|
| `Category` | name | категория товара |
| `Product` | category, name, description, price, in_stock | товар |
| `CartItem` | user, product, quantity (пара user+product уникальна) | строка корзины |
| `Order` | user, created_at, total | оформленный заказ |
| `OrderItem` | order, product, quantity, price | строка заказа с ценой на момент покупки |

## Адреса

| Адрес | Что делает | Доступ |
|---|---|---|
| `/` | каталог | все |
| `/product/<id>/` | страница товара | все |
| `/register/` | регистрация | все |
| `/accounts/login/`, `/accounts/logout/` | вход и выход | все |
| `/cart/` | корзина | вошедшие |
| `/cart/add/<id>/` | добавить в корзину (POST) | вошедшие |
| `/cart/remove/<id>/` | удалить из корзины (POST) | вошедшие, только свои строки |
| `/cart/checkout/` | оформить заказ (POST) | вошедшие |
| `/orders/` | мои заказы | вошедшие |
| `/admin/` | управление товарами | только администратор |

## HTTP-статусы

- **200** — страница открыта.
- **302** — перенаправление (например, на страницу входа, если пользователь не вошёл).
- **400** — оформление пустой корзины.
- **403** — запрос формы без CSRF-токена.
- **404** — товар или строка корзины не найдены (в том числе чужая строка).
- **405** — действие, меняющее данные, вызвано методом GET вместо POST.
